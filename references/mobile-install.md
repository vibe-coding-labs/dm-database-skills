# 达梦数据库移动端安装与连接指引

本文档汇总达梦数据库在 Android 与 iOS 上的可达方式与限制。达梦官方移动端支持以嵌入式 SDK / 移动管理工具 / 远程 JDBC 三类方式为主，具体可用性以当前官方发布为准。

## 1. 总览

| 方式 | Android | iOS | 适用场景 |
|------|---------|-----|---------|
| 远程 JDBC/ODBC | ✅ | ✅ | 移动 App 通过服务端 IP 访问 DM8 |
| 移动端 SDK / 嵌入式 | ✅ 见官方渠道 | ⚠️ 视版本 | 需要在设备侧使用轻量数据库能力 |
| disql / 管理工具 | ❌ | ❌ | 官方工具无移动端客户端，以远程连接为主 |

> 若你当前目标是“在手机上管理/查询达梦”，推荐走 **远程 JDBC** 或 **Web 管理入口**。

## 2. Android

### 2.1 通过 JDBC 远程连接

在 Android 应用内使用 DM JDBC 驱动连接服务端：

1. 准备 `DmJdbcDriver18.jar`，放入 App 的 `libs/` 或按 Gradle 引入。
2. 网络侧确保能访问服务端 IP:端口，例如 `jdbc:dm://<host>:5236`。
3. 连接参数与桌面端一致：`user / password / database / schema`。

### 2.2 使用 ODBC/JDBC 桥接工具

部分移动端 SQL 客户端支持添加 JDBC 连接：

- 输入驱动类与 jar 路径
- 填写 URL、账号、密码
- 测试连接并执行 SQL

### 2.3 常见问题

| 问题 | 解决 |
|------|------|
| 驱动加载失败 | 确认 `DmJdbcDriver18.jar` 已放入依赖或 assets |
| 网络不通 | 检查 VPN、防火墙、端口、域名解析 |
| 线程限制 | 数据库连接建议在工作线程执行，避免阻塞主线程 |

## 3. iOS

### 3.1 通过远程 JDBC/ODBC 访问

iOS 侧没有官方原生客户端时，优先使用支持 JDBC/ODBC 的远程 SQL 工具，或让后端提供 API/Web 管理入口。

### 3.2 通过 Web/API 管理

若服务端已部署 Web 管理平台，可直接在 Safari 中访问。

## 4. 运维注意

- 移动端访问默认不建议直连生产库，应通过 API 网关或只读副本。
- 如需本地存储，优先确认达梦当前版本提供的嵌入式方案与平台支持范围。
